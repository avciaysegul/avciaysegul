## Recent work

- **Device control interface · MAY Fren Sistemleri internship (2026).** I redesigned the control screens of a device after watching operators use the first version. Built with React, TypeScript, Tailwind CSS and Tauri, with the device-side logic kept in Lua. The code belongs to the company and is not public.
- **[Mutfakta Bugün](https://github.com/avciaysegul/YemekTarifleri-Tauri).** A desktop recipe app that asks questions while you cook and adapts quantities and steps to your answers. It has 22 recipes, each written as a Lua scenario and run from Rust. Built with Tauri 2, React, TypeScript, Rust and Lua.
- **Quantum key distribution on a Raspberry Pi · SAVTEK 2026.** A team project in which we modeled BB84 and B92 on a Raspberry Pi and detected eavesdropping through QBER. We presented it as a paper at SAVTEK 2026. [Case study and live demo](https://avciaysegul.github.io/en/projects/quantum-key-distribution.html)
- **[Allerra Kitchen](https://github.com/avciaysegul/GuvenliMenu).** A restaurant menu that filters dishes by allergen, with a reservation panel. Built with Wails, Go and Vue 3.
